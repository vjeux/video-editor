# Cutline — browser video editor

A non-linear video editor that runs entirely in the browser. Media decoding,
frame extraction and MP4 export are powered by
[Mediabunny](https://mediabunny.dev/); tooling is
[Vite+](https://viteplus.dev/) (`vp`).

## Develop

```bash
vp install
vp dev
```

| Command    | What it does                |
| ---------- | --------------------------- |
| `vp dev`   | Start the dev server        |
| `vp check` | Format, lint and type-check |
| `vp test`  | Run the unit tests          |
| `vp build` | Production build            |
